Consent Mode order

Pushes a consent default and a config command for the fake tag G-PWTEST0001 to the dataLayer, in the order the query gives, and sends one GA4 page_view hit with a denied gcs and gcd. The default comes first. With order=late the config command comes first. With grant=ad the default grants ad_storage and denies the other three. The page has a banner that the fixture rules answer. With update=early or update=late no hit is sent at load: the answer sends the hit 100 ms later and pushes a consent update that grants all four signals, at once for early (before the hit) and 300 ms after the answer for late (after the hit).
