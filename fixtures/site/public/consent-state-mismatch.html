Consent state mismatch

Pushes a consent update that grants all four signals, then 200 ms later one that denies all four, and 2500 ms after the denial sends one GA4 page_view hit for the fake tag G-PWTEST0001 that says granted in its gcs and gcd. With leak=1 the denying update also holds an extra key with a test token. With frame=1 the page makes no push and sends no hit itself: it embeds /consent-state-mismatch-frame, which does the same.
