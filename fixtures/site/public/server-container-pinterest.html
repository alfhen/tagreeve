Server container Pinterest

Sends a Pinterest tag addtocart hit with event ID pw-pin-event-1 to ct.pinterest.com, then a POST /capi?pinterest=add_to_cart to the mock server container host, which --server-container sends to the local container instead. The stand-in container then also calls the Pinterest Conversions API. ?email= is the email in that body. ?eid= is the event ID of the container call (default pw-pin-event-1). ?delayMs= loads the consent banner, sends once the first consent answer is given, and asks the stand-in container to wait that long before it sends on.
