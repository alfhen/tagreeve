Consent Mode hits

Sends one GA4 page_view hit for the fake tag at once, with the gcs and gcd given in the query. The page has no banner. With push=default it first pushes a consent default to the dataLayer. With push=relay a sandboxed child frame posts a consent default as a plain object with the keys 0, 1 and 2, and this page pushes it to the dataLayer. With push=stamped the page pushes a consent default as a plain object with the keys 0, 1 and 2 through a push wrapper that sets gtm.uniqueEventId on it: after the inner push by default, before it with when=before, and with order=inner the wrapper is the array's own push before the recorder first hooks it.
